## 🚀 시작하기

### 저장소 클론

```bash

```

### 필수 조건

이 저장소는 다양한 실험을 위한 공간이므로, 각 프로젝트나 테스트에 따라 필요한 환경이 다를 수 있습니다.

```

```

## 🔧 사용 방법

1. 테스트하고 싶은 기능이나 코드를 작성합니다
2. 변경사항을 커밋합니다
3. 필요시 브랜치를 생성하여 실험합니다
4. 테스트가 완료되면 main 브랜치에 머지합니다

```bash
# 새 브랜치 생성
git checkout -b feature/new-test

# 변경사항 스테이징
git add .

# 커밋
git commit -m "테스트: 새로운 기능 추가"

# 푸시
git push origin feature/new-test
```
